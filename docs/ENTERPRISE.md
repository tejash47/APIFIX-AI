# APIFIX AI — Enterprise Readiness & Compliance

APIFIX AI provides dedicated enterprise infrastructure, identity integration, and compliance controls.

## Enterprise Features

1. **Identity & Directory Sync**:
   - Single Sign-On via SAML 2.0 (Okta, Azure AD) and OIDC.
   - SCIM 2.0 Automated User & Group Provisioning (`/scim/v2/Users`, `/scim/v2/Groups`).
2. **Dedicated Worker Clusters**:
   - Customer-isolated worker pools with guaranteed CPU/Memory reservation.
3. **Continuous Compliance**:
   - Automated SOC2 and ISO27001 audit ledger exports (`/api/exports/audit.json`).
   - Immutable tamper-evident Merkle hash verification (`/api/compliance/verify`).
4. **Service Level Agreements**:
   - 99.99% Availability SLA with 15-minute P1 incident response windows.
